# Kami Plan - 内容规划模块

## 功能

分析内容素材，生成幻灯片大纲，展示给用户确认，支持修改迭代。

## 输入参数

从 kami-input 接收：
- `integrated_content`: 整合后的内容素材

## 输出

确认后的大纲结构。

## 大纲结构定义

```
{
  "slides": [
    {
      "page_type": "cover",
      "title": "主标题",
      "subtitle": "副标题",
      "author": "演讲人（可选）",
      "date": "日期"
    },
    {
      "page_type": "content",
      "page_number": 1,
      "title": "页面标题",
      "content_type": "data | list | comparison | timeline | quote | paragraph",
      "summary": "一句话总结",
      "content": {
        // 根据内容类型不同结构
      }
    },
    // ... 更多内容页
    {
      "page_type": "end",
      "title": "感谢语（四字）",
      "author": "演讲人（可选）",
      "date": "日期"
    }
  ]
}
```

## 内容类型识别规则

按优先级判断（从高到低）：

| 优先级 | 类型 | 识别特征 |
|--------|------|----------|
| 1 | **data** | 包含数字、百分比、统计数据、对比数据 |
| 2 | **comparison** | 包含"vs"、"对比"、"区别"、两对象对比 |
| 3 | **timeline** | 包含时间节点、年份序列、阶段划分 |
| 4 | **quote** | 包含引用符号、名人名言、金句 |
| 5 | **list** | 包含列表项、要点、条目（无数据特征） |
| 6 | **paragraph** | 纯文本段落（默认类型） |

## 执行步骤

### Step 1: 分析内容

1. 识别主题核心
2. 提取关键信息点
3. 判断每个信息点的最佳展示类型
4. 规划页面数量（建议 5-10 页）

### Step 2: 生成大纲

按照以下结构生成：

**封面页：**
- 标题：核心主题
- 副标题：补充说明或时间范围

**内容页：**
- 每页一个核心观点
- 标题简洁有力
- 摘要一句话概括
- 标注内容类型

**尾页：**
- 四字感谢语（如：谢谢观看、感谢聆听）

### Step 3: 展示大纲

格式化输出大纲：

```
📋 幻灯片大纲

【封面】
标题：xxx
副标题：xxx

【第1页】标题：xxx
类型：数据型
摘要：一句话总结

【第2页】标题：xxx
类型：对比型
摘要：一句话总结

...

【尾页】
感谢语：谢谢观看
```

### Step 4: 用户确认

询问用户：
```
内容规划是否满意？
1. 确认继续
2. 修改大纲
```

**选择"修改大纲"：**
- 接收用户具体修改意见
- 重新生成大纲
- 再次展示确认

### Step 5: 输出确认大纲

用户确认后，输出结构化大纲数据。

## 页面数量建议

| 内容量 | 建议页数 |
|--------|----------|
| 少量（1-3个要点） | 5-6页 |
| 中等（4-6个要点） | 7-8页 |
| 较多（7+要点） | 9-10页 |

**注意：** 每页内容不宜过多，保持简洁清晰。

## 示例

**输入内容：** 造车新势力对比相关素材

**生成大纲：**
```
📋 幻灯片大纲

【封面】
标题：造车新势力对比
副标题：2024年度核心指标分析

【第1页】标题：市场格局
类型：data
摘要：造车新势力2024年销量排名

【第2页】标题：销量对比
类型：comparison
摘要：理想 vs 蔚来 vs 小鹏 vs 问界

【第3页】标题：技术路线
类型：comparison
摘要：增程/纯电/换电技术路线对比

【第4页】标题：智能驾驶
类型：data
摘要：NOA落地城市数与算力对比

【第5页】标题：财务表现
类型：data
摘要：营收与毛利率分析

【第6页】标题：总结展望
类型：list
摘要：行业趋势与竞争格局

【尾页】
感谢语：谢谢观看
```
