# Kami Preview - 交付预览模块

## 功能

自动打开浏览器预览生成的幻灯片，收集用户反馈，支持迭代优化。

## 输入参数

- `html_path`: 生成的HTML文件路径
- `outline`: 幻灯片大纲（用于迭代时参考）

## 输出

用户确认完成，或返回修改意见。

## 执行步骤

### Step 1: 打开浏览器

使用系统命令打开浏览器：

```bash
# macOS
open {html_path}

# Windows
start {html_path}

# Linux
xdg-open {html_path}
```

**打开失败处理：**
```
浏览器打开失败，请手动打开文件：
{html_path}
```

### Step 2: 用户确认

展示确认选项：

```
幻灯片已生成，请在浏览器中预览。

幻灯片是否满意？
1. 完成
2. 需要优化
```

### Step 3a: 完成流程

用户选择"完成"：

```
✅ 幻灯片已生成完成！

文件路径：{html_path}
总页数：{total_pages} 页

提示：
- 点击页面左侧/右侧或使用键盘左右键切换页面
- 按 ESC 键退出全屏模式
```

### Step 3b: 迭代优化

用户选择"需要优化"：

```
请描述您想要的修改：

示例：
- 第2页数据需要更新为最新数据
- 第3页图表改为饼图
- 增加一页关于xxx的内容
- 删除第5页
- 整体风格改为深色主题
```

**接收修改意见后：**

1. 分析修改意见
2. 判断修改范围：
   - **内容修改**：返回 kami-generate 重新生成
   - **主题修改**：返回 kami-theme 重新选择
   - **大纲修改**：返回 kami-plan 重新规划

```
修改类型：内容修改
正在重新生成...

[进度提示]

已完成修改，请刷新浏览器查看。
```

## 迭代类型判断

| 修改意见关键词 | 返回阶段 |
|----------------|----------|
| 数据、数字、图表、文字、图片 | kami-generate |
| 主题、风格、颜色、深色、浅色 | kami-theme |
| 增加、删除、调整页面、大纲 | kami-plan |

## 完成后清理

如果生成了预览文件，询问是否保留：

```
是否保留主题预览文件？
1. 保留
2. 删除
```
