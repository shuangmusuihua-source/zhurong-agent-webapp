# Kami HTML Slides - 主入口

## 简介

Kami HTML Slides 是一个交互式HTML幻灯片生成Skill，专为中文内容设计。基于用户输入（话题/文本/文件），通过大模型进行内容规划、布局排版，最终输出HTML格式幻灯片，自动打开浏览器供用户预览和迭代优化。

## 使用方式

用户输入以下任一内容即可启动：

- `/kami` - 启动Skill
- `/kami [话题]` - 直接输入话题
- `/kami [文件路径]` - 直接指定文件

## 执行步骤

### Step 1: 启动与输入处理

**如果用户直接调用 `/kami`：**

1. 询问用户输入内容
2. 读取 `kami-input.md` 执行输入处理
3. 获取整合后的内容素材

**如果用户直接提供话题或文件路径：**

1. 直接读取 `kami-input.md` 执行输入处理
2. 获取整合后的内容素材

### Step 2: 内容规划

1. 读取 `kami-plan.md`
2. 传入内容素材
3. 大模型生成幻灯片大纲
4. 展示大纲，用户确认或修改
5. 获取确认后的大纲

### Step 3: 主题选择

1. 读取 `kami-theme.md`
2. 传入确认大纲
3. 询问是否需要预览
4. 根据用户选择执行快速路径或预览路径
5. 获取选中的主题信息

### Step 4: 幻灯片生成

1. 读取 `kami-generate.md`
2. 传入大纲和主题信息
3. 显示进度提示
4. 遍历每页，分析内容类型
5. 实时生成HTML结构
6. 配置图表和动画
7. 组装完整HTML文件
8. 获取HTML文件路径

### Step 5: 交付预览

1. 读取 `kami-preview.md`
2. 传入HTML文件路径
3. 自动打开浏览器预览
4. 用户确认或提出优化意见
5. 如需优化，返回对应阶段
6. 如满意，流程结束

## 技术栈

| 技术 | 选型 |
|------|------|
| 图标字体 | Lucide Icons |
| 图表库 | ECharts |
| 动画 | CSS动画 + Animate.css |
| 字体 | 阿里普惠体（本地） |
| 输出格式 | 单HTML文件（内嵌CSS/JS） |
| 导航方式 | 点击切换 + 键盘左右键 |

## 注意事项

1. **禁止使用emoji** - 所有图标使用 Lucide Icons
2. **字体本地引用** - 阿里普惠体需本地部署
3. **视口适配** - 每页严格100vh，无滚动
4. **响应式** - 支持不同屏幕尺寸
5. **进度提示** - 生成阶段必须显示进度信息
