# Kami Input - 输入处理模块

## 功能

处理用户输入，根据输入类型决定是否联网检索，输出整合后的内容素材。

## 输入参数

从主模块接收：
- `input_type`: "topic" | "text" | "file"
- `input_content`: 用户输入的内容

## 处理逻辑

```
┌─────────────────────────────────────────────────────┐
│                  输入判断                            │
└─────────────────────────────────────────────────────┘
                        │
        ┌───────────────┼───────────────┐
        │               │               │
        ▼               ▼               ▼
   【话题输入】     【文本输入】     【文件输入】
        │               │               │
        ▼               ▼               ▼
   自动联网检索    询问是否检索     读取文件内容
        │               │               │
        │               ▼               │
        │          是──►检索      询问是否检索
        │               │               │
        ▼               ▼               ▼
   整合素材 ◄─────────────────────────────┘
```

## 执行步骤

### Step 1: 判断输入类型

**话题输入（短文本）：**
- 判断条件：文本长度 < 50 字符 且 不包含换行符
- 处理：直接联网检索相关材料

**文本输入（Markdown/长文本）：**
- 判断条件：文本长度 >= 50 字符 或 包含换行符/Markdown标记
- 处理：询问用户是否需要联网检索更多材料

**文件输入：**
- 判断条件：以文件路径形式提供（.txt 或 .md）
- 处理：读取文件内容，然后询问是否检索

### Step 2: 联网检索

当需要联网检索时：

1. 使用 WebSearch 工具搜索话题相关内容
2. 搜索关键词提取：
   - 从话题/标题中提取核心关键词
   - 添加年份限定（当前年份：2026）
3. 整合检索结果到内容素材

**搜索策略：**
- 第一次搜索：话题 + "2026 数据"
- 第二次搜索：话题 + "对比 分析"
- 第三次搜索（可选）：话题 + "趋势 未来"

### Step 3: 输出内容素材

输出结构：
```
{
  "source": "topic" | "text" | "file",
  "original_input": "用户原始输入",
  "search_performed": true | false,
  "search_results": [
    {
      "title": "搜索结果标题",
      "url": "来源URL",
      "summary": "内容摘要"
    }
  ],
  "integrated_content": "整合后的完整内容素材"
}
```

## 边缘情况处理

| 情况 | 处理方式 |
|------|----------|
| 文件不存在 | 提示"文件未找到，请检查路径"，重新询问 |
| 文件格式不支持 | 提示"仅支持 .txt 和 .md 文件"，重新询问 |
| 文件内容为空 | 提示"文件内容为空"，重新询问 |
| 网络检索失败 | 提示"网络检索失败，将基于已有内容继续" |

## 示例

**输入：** "造车新势力对比"

**处理：**
1. 判断为话题输入（短文本）
2. 自动联网检索
3. 搜索关键词：["造车新势力 2026 数据", "造车新势力 对比 分析"]

**输出：**
```
已检索到相关材料：
- 理想汽车2024年交付50.6万辆
- 蔚来2024年交付22.4万辆
- 小鹏2024年交付19万辆
- 问界2024年交付37.1万辆
...
```
