# Kami Theme - 主题选择模块

## 功能

展示可用主题，支持预览，让用户选择合适的主题风格。

## 输入参数

从 kami-plan 接收：
- `outline`: 确认后的幻灯片大纲

## 输出

选中的主题信息。

## 可用主题

| 主题ID | 主题名称 | 风格描述 | 模板路径 |
|--------|----------|----------|----------|
| business-modern | 商务现代白 | 清新绿色系、毛玻璃卡片、弥散渐变背景 | templates/business-modern/ |
| business-modern-dark | 商务现代黑 | 深色背景、绿色系点缀、毛玻璃质感 | templates/business-modern-dark/ |
| business-simple | 商务简白 | 简约风格、白底深字、清新配色 | templates/business-simple/ |

## 执行步骤

### Step 1: 询问是否预览

```
是否需要主题预览？
1. 是，先看看效果
2. 否，直接选择
```

### Step 2a: 预览路径（选择预览）

**用户选择主题：**

询问用户想要预览哪些主题（最多3个）：

```
可选主题：
1. 商务现代白 - 清新绿色系、毛玻璃卡片、弥散渐变背景
2. 商务现代黑 - 深色背景、绿色系点缀、毛玻璃质感
3. 商务简白 - 简约风格、白底深字、清新配色

请选择要预览的主题（可多选，最多3个，如：1,2 或 1,2,3）：
```

**生成预览页面：**

为每个选中的主题生成一个独立的预览HTML文件，每个文件展示完整的一页幻灯片效果。

**预览文件命名规则：**
```
{project-dir}/theme-preview-{theme-id}.html
```

示例：
- `theme-preview-business-modern.html`
- `theme-preview-business-modern-dark.html`
- `theme-preview-business-simple.html`

**预览页面内容：**
- 使用大纲中的第一个内容页作为预览内容
- 完整展示该主题的视觉效果
- 包含标题、摘要、数据卡片/图表等元素

**打开浏览器预览：**

按顺序打开所有选中的主题预览文件，用户可以在浏览器标签页间切换对比。

```
正在生成预览...
[1/2] 商务现代白... ✓
[2/2] 商务现代黑... ✓

已打开 2 个预览页面，请在浏览器中查看对比。

请选择主题（输入编号）：
1. 商务现代白
2. 商务现代黑
```

### Step 2b: 快速路径（不选择预览）

直接展示主题列表，用户单选：

```
可选主题：

1. 商务现代白 - 清新绿色系、毛玻璃卡片、弥散渐变背景
2. 商务现代黑 - 深色背景、绿色系点缀、毛玻璃质感
3. 商务简白 - 简约风格、白底深字、清新配色

请选择主题（输入 1/2/3）：
```

### Step 3: 用户选择

接收用户输入，确认选择。

**输出结构：**
```
{
  "theme_id": "business-modern",
  "theme_name": "商务现代白",
  "template_path": "~/.claude/skills/kami-html-slides/templates/business-modern/"
}
```

## 预览页面生成规范

**每个预览页面包含：**

1. 完整的HTML结构（单文件，内嵌CSS/JS）
2. 使用大纲中第一个内容页的真实内容
3. 展示该主题的完整视觉效果：
   - 背景样式
   - 标题区域
   - 摘要区域
   - 内容区域（数据卡片/图表/列表等）
   - 页码

**示例预览页面结构：**
```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>主题预览 - 商务现代白</title>
  <!-- 完整的主题样式 -->
</head>
<body>
  <div class="webgl-background"></div>
  <div class="slide">
    <div class="title-region">...</div>
    <div class="summary-region">...</div>
    <div class="content-region">...</div>
    <div class="page-number-region">预览页面</div>
  </div>
</body>
</html>
```
