祝融 Agent 色彩规范

基于 designsystems.com 方法论与 Radix Colors 12 阶色阶体系，构建可访问、可扩展的色彩系统。主色为蓝绿色（HSL 192），搭配琥珀色强调色与冷灰色中性色阶。

v2.0 · 基于 Radix Colors 方法论
参考: designsystems.com · Nathan Curtis · Radix Colors

方法论来源

色彩系统基于 designsystems.com 推荐的最佳实践，核心参考 Nathan Curtis 的 16 条色彩设计原则与 Radix Colors 的 12 阶色阶体系。

#1
色阶而非单色
每种颜色定义 12 个明度步骤（tint → base → shade），覆盖从最浅背景到最深文字的所有场景，而非仅定义一个主色值。
#2
语义化命名
组件引用语义 Token（如 --primary、--destructive）而非色阶步骤号。Token 映射到色阶步骤，暗色模式只需切换映射。
#3
对比度优先
色阶设计保证高阶色（11-12）与低阶色（1-2）组合自动满足 WCAG AA（4.5:1），无需逐个检查。
#4
暗色模式反转
暗色模式下色阶方向反转：低阶变深、高阶变浅。语义映射不变，仅替换 CSS 变量组。
#5
强调色隔离
主色与强调色（Accent）分属不同色相，避免同色系混淆。强调色仅用于需要额外注意的元素，如用户头像、重要标记。
#6
中性色带色相
中性色阶不是纯灰，而是带有微弱色相（HSL 220 冷灰），与主色色温一致，避免纯灰与蓝绿色系不协调。

主色阶 — Teal / Cyan

主色 HSL 192，12 阶从浅到深。步骤 7 为品牌主色，用于按钮、链接、焦点环等核心交互元素。色相从 v1 的 199 调整为 192，更偏青色，与冷灰中性色阶更协调。
